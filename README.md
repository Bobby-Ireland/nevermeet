# NEVERMEET

**Match. Flirt. Never meet.**

A mobile-first, fictional dating simulation. Swipe 40 profiles, choose Everyone / Women / Men, add a Plot Twist, match and chat without arranging an actual date.

## Start here

To upload this project and put it online, follow [START_HERE.md](START_HERE.md). You do not need to run code on your computer to use the GitHub + Cloudflare Pages route.

This is a standalone Next.js export of the latest NEVERMEET site, including the mobile text-spacing correction. It has no dependency on ChatGPT hosting or login. The original hosted site is a separate publication; updates do not sync between the two automatically.

## Features

- 20 fictional women and 20 fictional men, with locally bundled portraits.
- Mouse/touch swiping, keyboard controls, pass, like, Plot Twist and rewind.
- Simulated matches and context-sensitive, scripted chat replies.
- Mobile and desktop layouts, reduced-motion support and accessible controls.
- No app accounts, database, analytics, cookies or external AI API.
- Messages live in the current browser tab's memory and disappear on refresh.

The replies are scripted locally; they are not generated by a remote AI model. The website code does not send chat messages to a server. Hosting providers may maintain their own standard request logs.

## Run locally

Install Node.js 24 and pnpm 11.25.0. The project pins its package manager and includes a lockfile.

```sh
npm install --global pnpm@11.25.0
pnpm install --frozen-lockfile
pnpm dev
```

Open the local address printed by Next.js (normally http://localhost:3000).

## Check and build

```sh
pnpm typecheck
pnpm build
pnpm preview
```

The build creates a complete static website in `out/`. The preview command serves that build at http://localhost:3000; it requires no additional package download. Use Ctrl+C to stop either server. The preview server is for local checking, not public hosting.

The included GitHub workflow runs the type check and build on pushes to `main` and pull requests. It does not publish a website or need deployment secrets.

See [BUILD_CHECKS.md](BUILD_CHECKS.md) for the checks performed on this export.

## Edit the site

| File | Purpose |
| --- | --- |
| `app/page.tsx` | Landing page, swipe flow, matches and scripted conversations |
| `app/globals.css` | Branding and responsive styles |
| `app/layout.tsx` | Page title, description and favicon |
| `lib/profiles.ts` | Fictional identities, preferences, bios and openers |
| `public/portraits/` | All 40 locally served portrait images |
| `next.config.ts` | Portable static-export configuration |

Keep profile identities fictional. Add portraits under `public/portraits/`, update `lib/profiles.ts`, and record asset provenance in [ASSETS.md](ASSETS.md).

## Hosting

The included configuration targets a website at the root of a domain, such as a Cloudflare Pages address or a custom domain. Build with `pnpm build` and publish `out/`.

GitHub stores the source; uploading it alone does not publish the website. GitHub Pages project URLs under a repository subdirectory need additional base-path and image-path configuration, so use the Cloudflare Pages instructions supplied here.
